# Security policy

## Supported development state

Granit Survival is currently a prototype. The active GitHub Actions workflow builds a debug APK; a signed production release pipeline is not enabled.

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use **Security → Advisories → Report a vulnerability**. Otherwise, contact the repository owner privately through GitHub before disclosing details publicly.

## Protecting credentials and local data

- Never commit passwords, access tokens, private keys, keystores, or local secret files.
- Do not paste credentials or signing material into issues, pull requests, or chat.
- Keep local backups of important game saves before installing test builds.
- Treat debug APKs as development artifacts, not production releases.
